单词大战僵尸 PWA v2.1.0 发布包

适用设备：iPad、iPhone、安卓手机/平板、Windows、macOS。

使用方式：
1. 将本目录全部文件原样上传到支持 HTTPS 的静态网站根目录。
2. 上传后把同一个 HTTPS 链接发给使用者。
3. iPad/iPhone：使用 Safari 打开，点“分享”→“添加到主屏幕”。
4. 安卓/电脑：使用 Chrome 或 Edge 打开，选择“安装应用”。
5. 第一次使用先在开战页点“试听发音”。

学习数据：
- 首次打开自动创建“孩子”档案。
- 同设备可新建多个学习档案，进度互不影响。
- 当前没有访客模式；朋友试玩前请新建独立档案，试玩后可删除该档案。
- 如果浏览器禁止 IndexedDB，游戏会停止开局，避免产生无法保存的学习结果。
- 学习记录保存在当前设备、当前浏览器、当前网址的 IndexedDB 中。
- 更换设备或网址不会自动同步，请在“学习进度”中导出 JSON 备份，再到另一台设备导入。
- 浏览器清理网站数据前应先导出备份。

注意：
- index.html 必须位于网站根目录。
- 正式安装和稳定离线缓存需要 HTTPS。
- 不要在移动设备上直接双击 index.html，应通过 HTTPS 地址访问。
- iPad 若试听无声：在“设置→辅助功能→朗读内容→声音”中下载英语声音。
- 国行安卓若试听无声：在系统设置中搜索“文字转语音”或“TTS”，安装并启用英语语音数据。
- 游戏使用系统动态发音，可直接覆盖当前 3,180 词。
