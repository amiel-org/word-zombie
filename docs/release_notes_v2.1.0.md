# 单词大战僵尸 v2.1.0

## 主要更新

- 取消访客模式。所有关卡必须绑定学习档案并在开战前成功创建学习局。
- 新增档案删除，级联清除该档案的学习局、答题日志和单词进度；最后一个档案受保护。
- 新增 8 张校园战场地图，按每个档案的开局次数独立循环。
- 优化动态选词：最多 12 个错词/到期词，其余优先未接触词；无到期词时不立即重复上一局。
- 看板“已练局数”只统计已完成关卡，不再把中途退出的活动学习局算作完成。
- Windows 固定端口被占用时会校验目标 manifest，避免误把其他本机网站当成游戏。
- IndexedDB 初始化失败时禁止开局；战斗中发生保存失败也会显示明确提示。

## 内容与兼容性

- 高中高频 660、中频 1,320、低频 1,200，共 3,180 个唯一词条。
- 支持 PWA、Windows x64 单文件版、iPad Safari、安卓 Chrome 和桌面 Chrome/Edge。
- 当前仍为本地档案，没有账号和自动云同步；跨设备迁移使用 JSON 导出/导入。
