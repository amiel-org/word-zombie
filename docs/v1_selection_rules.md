# V1 Selection And Level Rules

## Core selection

Each unit contributes forty entries, for a first battle pool of two hundred.
An entry may enter the pool only when all of the following are true:

1. It is marked as a curriculum entry in the textbook.
2. It is a word or phrase, not a proper noun.
3. The transcription is not marked for manual review.

Within those constraints, selection prioritizes general high-school reading
utility, confusing or multi-sense entries, and important textbook phrases.
Highly specialized entries and redundant members of the same word family are
kept in the expansion pool.

Entries requiring review remain in the master dataset and can be promoted
after correction.

## Level structure

- Five chapters map to textbook Units 1-5.
- Each chapter contains five levels.
- Levels 1-4 each introduce ten new entries in textbook order.
- Level 5 introduces no new entries and runs a personalized boss review.
- Each ordinary level contains twenty encounters. Empty slots are filled at
  runtime with due reviews and recent weak entries.
- The chapter boss selects up to five actual weak entries. If there are not
  enough weak entries, the game uses fallback candidates with multiple senses,
  phrases, or longer spellings.

## Mastery

- A first-attempt correct answer is valid recognition evidence.
- A second- or third-attempt correct answer completes the encounter but does
  not count as mastery.
- A word becomes firmly mastered only after correct recalls on at least three
  different days, including one review after seven or more days.
